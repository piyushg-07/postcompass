# PostCompass website

The PostCompass landing page and downloads site, built with [Next.js](https://nextjs.org).

From the repository root:

```bash
pnpm dev:web   # or: pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000). Pages live in `app/`; start with `app/page.tsx`.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the rest of the monorepo.
